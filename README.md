# Sai's Blog

Sai 的个人博客，记录学习、围棋和生活。

- 网站：<https://saiiijchan.github.io/>
- 框架：[Astro](https://astro.build/)
- 主题：[AstroPaper](https://github.com/satnaing/astro-paper)
- 托管：GitHub Pages

## 本地开发

```bash
corepack pnpm install
corepack pnpm dev
```

打开 <http://localhost:4321/> 查看博客。

## 新建文章

在 `src/content/posts/` 中新建 Markdown 文件。可以复制现有文章作为模板。

## 构建

```bash
corepack pnpm run build
```
